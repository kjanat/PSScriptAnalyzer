## Install

Download the `.tgz` asset, then install it directly:

```sh
npm install ./psscriptanalyzer-formatter-wasm-<version>.tgz
```

The package contains the parser-backed PowerShell formatter for browsers and Node.js, including its
.NET WebAssembly runtime, TypeScript declarations, and MIT license. The license identifies Microsoft
Corporation and Kaj Kowalski as copyright holders. The package does not start `pwsh`, `dotnet`, or
another formatter process at runtime.
