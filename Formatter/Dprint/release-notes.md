## Install

```sh
dprint add kjanat/PSScriptAnalyzer
```

The release contains the directly loadable dprint `plugin.wasm`, its formatter configuration
`schema.json`, its MIT `LICENSE`, and SHA-256 checksums for all three files. The module formats
`.ps1`, `.psm1`, and `.psd1` files without starting `pwsh`, `dotnet`, Node.js, or another formatter
process.
